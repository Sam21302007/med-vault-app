Here are the commands to start your local servers:

Option 1: Start Both Services Together (Recommended)
Run this single command from your root project folder (d:\SVAC REACT):

bash
npm start
This starts:

🟢 Express Backend: http://localhost:5001
🔵 React Frontend: http://localhost:8080


Option 2: Start Services in Separate Terminals (For Debugging)
Terminal 1 — Backend Only:

bash
npm run server

Terminal 2 — Frontend Only:

bash
npm run client
