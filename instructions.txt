✅ Short answer
Yes — this project is a full-stack app, not just React.

I checked package.json and server.js:

package.json defines:

npm run server → runs the Express backend
npm run client → runs the React frontend
npm start → starts both together with concurrently
server.js creates an Express app and mounts APIs like:

/api/auth
/api/appointments
/api/records
etc.
So the app is intentionally split into:

React frontend
Express backend API
Why you are starting two services
Because the frontend and backend are separate processes:

React dev server runs on port 8080
Express API runs on port 5001
package.json has "proxy": "http://localhost:5001" so browser requests are routed to the API
This is normal for a React + Express project.

This is not “just React”; it is React + Express backend. The project is designed to run as two services, but you do not need to start them manually if you use npm start.
